How the simulated adaptation works
  • Two focus actions on the same panel in one session trigger an adaptation decision.
  • Before a panel has two accepted suggestions, the system asks for confirmation.
  • After two accepted suggestions for that panel, the next session can apply the same low-risk change automatically when the toggle is on.
  • Rejecting a suggestion suppresses another prompt for that panel during the current session. Starting a new session clears the session focus counts but preserves learned preferences.
  • Undo reverses the latest layout change and reduces the acceptance count for that adaptation. “Reset learning” clears all local preferences and returns to the initial layout.

Scope: This is a deterministic, rule-based simulation of adaptive behaviour. It does not use a trained machine-learning model, external API, live operational data or real equipment telemetry. All displayed values are illustrative.

Student prototype for interaction-design assessment. No real operational decisions should be made using this demonstration.
